Verification & Installation

Package installation & checksum verification

Detailed platform installation commands and integrity checks.

Windows Installation

Verify checksum via PowerShell and execute installation.

PowerShell SHA-256 Verification
Get-FileHash -Algorithm SHA256 .\BitChat-0.3.1-windows-x64.exe
Silent Installation (Command Line)
.\BitChat-0.3.1-windows-x64.exe /VERYSILENT /SUPPRESSMSGBOXES

Linux Installation

Install via apt on Debian/Ubuntu or launch standalone AppImage.

Debian / Ubuntu Package Install
sudo apt install ./bitchat_0.3.1_amd64.deb
AppImage Execution
chmod +x BitChat-0.3.1-x86_64.AppImage && ./BitChat-0.3.1-x86_64.AppImage
Complete Uninstallation System: BitChat provides a dedicated uninstallation system. You can uninstall BitChat at any time via bitchat --uninstall, through Windows Add or Remove Programs, or using Debian's sudo apt purge bitchat. By default, your cryptographic identity in ~/.bitchat/identity.json is preserved to prevent accidental loss of peer identity; append --remove-user-data to wipe all local keys and configurations completely.
