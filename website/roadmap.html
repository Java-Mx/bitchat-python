Engineering Trajectory

Development Roadmap

Our multi-phase engineering trajectory: from a hybrid Python/Rust application to an autonomous, standalone native Rust mesh communication tool.

PHASE 1: COMPLETED (v0.3.1)

Rust Core Migration, Performance & Lifecycle Overhaul

November 2026

Established the foundational Rust/Python hybrid architecture using PyO3 and Maturin. Eliminated UI jitter, event loop blocking, and redundant serialization overhead while implementing an atomic uninstallation system.

✓ Native Rust Extension (_bitchat_core)
Maturin & PyO3 workspace crate providing wire-speed CRC32, framing, and routing.
✓ NativeStreamFramer & Packet Router
8-byte binary framing (BC\x01\x00) with memory-bounded replay deduplication.
✓ Dual Transport (BLE + LAN)
Linux BlueZ D-Bus and Windows WinRT peripheral/central plus LAN UDP/TCP sockets.
✓ Complete Uninstaller System
CLI uninstallation via bitchat --uninstall with optional --remove-user-data.
✓ Inno Setup & WinGet Distribution
Windows standalone installer and automated package manager submission manifest.
✓ Comprehensive Documentation Overhaul
Audited legal, security, architecture, and protocol documentation with unit test suite.
PHASE 2: IN PROGRESS (v0.4.x)

Intermediate Migration: ~60% Rust Core Ownership

Q1 2027

Transitioning core networking, socket state machines, and session lifecycle management directly into asynchronous Rust (Tokio), minimizing crossing overhead between Python and Rust.

• Tokio-Powered Async Network Engine
Move UDP discovery and TCP peer streams into native Tokio runtime threads.
• Zero-Copy PyO3 Buffer Sharing
Direct buffer views passing payloads between Rust core and Python UI without allocation.
• Adaptive MTU & BLE Reconnect Logic
Automatic MTU negotiation and exponential backoff retry state machine in Rust.
• Flathub & Debian PPA Distribution
Official Linux package repository presence for automated system package updates.
PHASE 3: PLANNED (v1.0.0)

Fully Native Rust Application

Future Objective

The ultimate architectural goal: complete retirement of the Python runtime, PyO3, and Maturin. BitChat will compile as a single, ultra-lightweight native Rust binary.

• 100% Native Rust TUI (Ratatui)
Replace Textual with a memory-safe, ultra-fast terminal UI engine written in pure Rust.
• Elimination of Python Runtime
Single standalone static binary with instantaneous sub-10ms startup and minimal RAM footprint.
• macOS Native CoreBluetooth Integration
Direct Rust bindings to Apple's CoreBluetooth frameworks without third-party CLI shims.
• Independent Third-Party Security Audit
Formal cryptographic review of the completed native Rust implementation by an accredited firm.
