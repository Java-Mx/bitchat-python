About BitChat Python

Author: Java-Mx & Contributors Version: 0.3.1 License: MIT

1. The Mission: Sovereign Local Communication

Contemporary digital communications overwhelmingly depend on centralized corporate infrastructure, cloud message brokers, domain name registries, and cellular data networks. When internet access is censored, disrupted during natural disasters, or monitored by network adversaries, these tools cease to function.

BitChat Python was created to solve this problem. It is a terminal-native, peer-to-peer mesh communications tool designed to operate without internet connectivity. Nodes discover one another directly over commodity Bluetooth Low Energy (BLE) radios and Local Area Networks (LAN), forming ad-hoc encrypted meshes where messages travel securely between peers.

2. Technical Architecture & The Rust Migration

BitChat is in the middle of a deliberate architectural evolution designed to maximize execution efficiency, memory safety, and cross-platform reliability:

CURRENT: v0.3.1 Python + Rust Native Core

Python coordinates high-level application orchestration, Textual TUI widgets, and async event loops. A native Rust crate (_bitchat_core) compiled via PyO3 and Maturin accelerates wire-speed packet framing, CRC32 verification, store-and-forward mesh routing, and replay deduplication.

INTERMEDIATE: PHASE 2 ~60% Rust Core Ownership

Moving physical transport state machines (Tokio async networking), session lifecycle management, and packet serialization fully into Rust, leaving Python solely responsible for the terminal user interface layer.

FINAL OBJECTIVE: PHASE 3 100% Standalone Native Rust Binary

Complete transition to a standalone compiled Rust binary using a Rust terminal UI framework (e.g. Ratatui). All Python, PyO3, and Maturin dependencies will be eliminated, yielding single-binary deployment with sub-10ms startup time and minimal memory consumption.

3. Open Source Philosophy

BitChat is built strictly in the public interest:

  • Zero Commercial Incentives: We have no corporate venture backing, token economics, or user monetization model.
  • Radical Transparency: Source code, build pipelines, release assets, and SHA-256 checksums are openly published on GitHub.
  • Full User Agency: The software does not track usage or force automatic updates. Users retain complete control over their hardware, network sockets, and identity keys.

4. Get Involved

BitChat is an open community project. We welcome code contributions, protocol reviews, testing reports on diverse hardware, and documentation improvements.
