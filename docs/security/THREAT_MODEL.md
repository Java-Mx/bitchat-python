# Threat Model

> **🚧 Planned**
> **UNVERIFIED**: The threat model has not yet been fully analyzed.

## Considered Vectors
- **BLE-range attackers**: Passive eavesdropping or active interference.
- **MITM (Man-in-the-Middle)**: Active interception of handshakes.
- **Replay attacks**: Resending captured packets.
- **Traffic analysis**: Inferring metadata from packet sizes and timings.
- **Key compromise**: Physical access to the device storing keys.
