System Requirements

  • Operating System: Windows 10 (version 1809 / build 17763 or newer) or Windows 11 (64-bit x64).
  • Transports: Bluetooth 4.0+ BLE adapter with Windows WinRT support, and/or Wi-Fi / Ethernet Local Area Network (LAN).
  • Disk Space: ~80 MB free disk space.
  • Privileges: Standard user account (installs to %LOCALAPPDATA%\Programs\BitChat by default; no Administrator rights required).
  • Runtime: Self-contained (Python, Textual, Bleak, WinRT, and Cryptography are bundled).

# Expected Hash: F08C9DFA91FE0F1755574D4C2055166E4B95782DBF6C92748B73B7A723F3BC3E

2. Check Authenticode Signature Status:

bitchat --help
bitchat --configure

Security, Code Signing & Windows SmartScreen

  • Authenticode vs. SmartScreen Reputation: An Authenticode digital signature verifies publisher identity and guarantees that the binary has not been modified since signing. Windows Defender SmartScreen additionally evaluates download reputation across Windows users; even newly signed installers may display a SmartScreen prompt until reputation is established.
  • Current Signing Status: NotSigned — No commercial code-signing certificate configured yet. Do not treat as a Microsoft-verified publisher until a real certificate signature is verified. Always verify the SHA-256 checksum below.
  • Never Disable Security Protections: Do not disable Windows Defender or SmartScreen in system settings. Instead, verify the SHA-256 hash above against the official GitHub Release checksum file (BitChat-0.2.0-windows-x64.exe.sha256).

Changelog & Troubleshooting

  • v0.2.0 Highlights: Self-contained Windows x64 installer 2.0 with official BitChat branding, Terms of Use & Privacy Policy wizard screens, user-scope default installation, safe PATH management, optional per-user Windows sign-in startup, and identity-preserving upgrades/uninstallation. Full history in CHANGELOG.md.
  • bitchat not recognized after install: Close and reopen your PowerShell or Command Prompt window so the updated user PATH takes effect.
  • Manage Windows Startup at any time: Run bitchat --startup status, bitchat --startup enable, or bitchat --startup disable, or re-run the installer.
  • BLE GATT Status 3 on Windows: Some Windows Bluetooth drivers restrict GATT peripheral hosting; BitChat keeps BLE Central scanning active and offers one-click fallback to LAN transport.
